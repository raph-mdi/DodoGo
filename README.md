# DodoGo

DodoGo est une petite alarme web simple et colorée. Elle permet de programmer une sonnerie après un nombre de minutes choisi.

## Utilisation

1. Saisir une durée en minutes.
2. Cliquer sur **Set** pour programmer l'alarme.
3. Cliquer sur **Snooze** pour repousser l'alarme de 5 minutes.
4. Cliquer sur **Stop** pour arrêter l'alarme.

## Lancer l'outil

Ouvrir le fichier `index.html` dans un navigateur web. Aucun serveur ni installation n'est nécessaire.

L'alarme utilise un fichier audio distant : une connexion internet peut donc être nécessaire pour entendre la sonnerie.
